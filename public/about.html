About HoopTrack

HoopTrack is a web application built for basketball fans who want quick access to game scores and player information without jumping between multiple websites.

How to Use

Home Page — View today's live NBA games with real-time quarter-by-quarter scores. Games currently in progress show a pulsing LIVE badge. Below that you'll find scores from the past 7 days. Click any recent game card to expand and see the quarter-by-quarter breakdown.

Players Page — Search for any NBA player by name. Each result shows their team, position, and height. You can save players to your Favorites list or add them to the Compare section.

Compare Players — Select two players from search results or your favorites list to compare their height and weight side by side in a bar chart.

My Favorite Players — Save players you want quick access to. Favorites are stored in a database so they persist across sessions. You can remove them at any time.

About the Data

All NBA data is powered by the BallDontLie API, which provides game scores, schedules, and player information. Game data updates in real time during live games.

Built With

Node.js, Express, Supabase, and Chart.js
